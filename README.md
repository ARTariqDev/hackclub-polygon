# hackclub-polygon

## About
A pretty basic FNAF model viewer/jumpscare simulator.

## Technical Details
The code is pretty basic too, besides making the models spin and using a basic circular queue/array for changing models/jumpscares/descriptions.
Theres 5 main arrays:
- Models (stores Model filepaths)
- Names (stores Model Names)
- Desc (stores descriptions for each character)
- Jumpscares (stores youtube video links for jumpscares for each character that will be played via an iframe embed)
- jumpscareDurations (stores video lengths after which we automatically close the iframe)
